# 好好唱 v1.1.3 · 安装与快速检查

1. 沿用原 Compose 项目、密码、端口和目录，只执行 `docker compose pull ktv` 与 `docker compose up -d --no-deps ktv`；不需要重建 CPU／NPU 容器。
2. 打开“设置与任务 → 在线资源”，确认登录卡片只剩“扫码登录／检测登录状态”，没有手动填写凭证的入口；核对账号正确。
3. 对之前失败的收藏夹任务点“重试未完成下载”，确认进度显示“下载画面／下载原唱”，完成后文件仍有画面与原唱。
4. 触发“立即同步已保存的收藏夹”，确认同步与下载都使用这份扫码登录，且不再出现网页解析类错误。
5. 用自有或已授权的测试视频验证下载清晰度符合该账号权限；4K 与 Hi-Res 需要大会员。若平台风控导致失败，任务错误应为 API 取流类的提示（线路、登录或权限），不再是 yt-dlp 的网页错误。
6. 核对原曲库、队列、歌房和 PC 配置。本版不改 APK 与分离镜像，客户端不必更新。

NAS 需更新才能获得本版改动。现有 APK、PC 整理器与分离镜像继续兼容。生产 NAS 的实际 NPU 设备访问和音质仍需部署后确认。
