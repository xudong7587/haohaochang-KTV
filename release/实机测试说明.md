# 好好唱 v1.1.2 · 安装与快速检查

1. 沿用原 Compose 项目、密码、端口和目录，只执行 `docker compose pull ktv` 与 `docker compose up -d --no-deps ktv`；不需要重建 CPU／NPU 容器。
2. 打开“设置与任务 → 在线资源”，确认只保留一处“B 站登录”，并核对“检测登录状态”显示的账号是升级前用的那个。
3. 在 1.1.1 分别登录过时，确认两份登录已合并：收藏夹设置（ID、间隔、启用状态）保留，另一份记录被删除。
4. 触发“立即同步已保存的收藏夹”，确认同步与收藏夹下载使用同一份 Cookie；收藏夹换账号时只在这一处重新扫码。
5. 用自有或已授权的测试视频验证下载清晰度符合该账号权限；4K 与 Hi-Res 需要大会员。
6. 核对原曲库、队列、歌房和 PC 配置。本版不改 APK 与分离镜像，客户端不必更新。

NAS 需更新才能获得本版改动。现有 APK、PC 整理器与分离镜像继续兼容。生产 NAS 的实际 NPU 设备访问和音质仍需部署后确认。
