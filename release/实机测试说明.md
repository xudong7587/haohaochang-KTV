# 好好唱 v1.1.1 · 安装与快速检查

1. 沿用原 Compose 项目、密码、端口和目录，只执行 `docker compose pull ktv` 与 `docker compose up -d --no-deps ktv`；不需要重建 CPU／NPU 容器。
2. 打开“设置与任务 → 在线资源”，分别确认“在线找歌 · B 站登录”和“收藏夹自动下载 · B 站登录”显示各自的账号，升级后两处应仍是原账号。
3. 在收藏夹一侧改用该收藏夹所属账号扫码，触发“立即同步已保存的收藏夹”，确认同步和下载正常。
4. 在在线一侧扫码登录另一个账号，确认在线搜索、预览和下载使用新账号，收藏夹一侧的登录与同步不受影响。
5. 用自有或已授权的测试视频验证下载清晰度符合该账号权限；失败提示只指出对应的一侧。
6. 核对原曲库、队列、歌房和 PC 配置。本版不改 APK 与分离镜像，客户端不必更新。

NAS 需更新才能获得本版改动。现有 APK、PC 整理器与分离镜像继续兼容。生产 NAS 的实际 NPU 设备访问和音质仍需部署后确认。
