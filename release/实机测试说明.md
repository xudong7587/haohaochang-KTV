# 好好唱 v1.1.4 · 安装与快速检查

1. 保留原 Compose 项目、端口和目录。首次迁移按使用手册替换 Compose；已有独立分离容器的项目只执行 `docker compose pull ktv` 和 `docker compose up -d --no-deps ktv`，CPU／NPU 镜像保持不变。
2. 打开 NAS 后台，以现有密码登录，关闭浏览器后重新打开，确认一周内免重新登录。在「设置与任务 → 管理密码」用当前密码改为至少 6 位的新密码，确认旧密码和旧登录失效。
3. 电视或手机安装 `haohaochang-tv-v1.1.4.apk`，同签名覆盖可保留原应用数据。检查左上角、桌面图标和网页图标均为紫底白色麦克风。
4. 在歌名和歌星点歌页按方向键：目标卡片仍完整显示时只移动焦点；第三行不滚，进入第四行才上移一行。实机预览使用 3840×2160／440 dpi 测试。
5. 核对原曲库、队列、歌房、PC 配置和播放。vivo CarLink 入口需要厂商平台接入，尚未在零跑 C11 实车验证。
