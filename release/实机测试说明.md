# 好好唱 v1.1.5 · 安装与快速检查

1. 等任务完成，保留原 Compose 项目、密码、端口和目录。用本包新版 Compose 填回原配置，执行 `docker compose pull` 和 `docker compose up -d`；本次必须同时更新主程序与 CPU／NPU 独立分离容器，不能只更新 ktv。ARM64 使用对应 Compose 文件。
2. PC 用 `haohaochang-resource-ai-v1.1.5.zip` 手动覆盖程序，保留 worker.json、runtime、.venv 和 data。首次新配对时，在 NAS「人声分离」读取配对码，再到 PC 本机详细页面核对并确认。
3. 打开 NAS 后台「设置与任务 → 管理密码」。改密默认同时退出旧播放、点歌设备；旧二维码和独立歌房凭据失效，需要重新登录或扫码，已点队列及曲库保留。也可单独点击退出所有设备。
4. 电视或手机可安装 `haohaochang-tv-v1.1.5.apk`，正式签名覆盖保留应用数据。确认点歌、原唱／伴奏切换和歌词显示；本次没有新增车载开发。
5. 核对整理器在线状态、曲库、队列和正式媒体目录。临时分离结果在 NAS 确认后至少保留 1 小时，其他完成／失败任务保留 7 天，再自动回收；NAS 已保存的正式资源不受影响。

本版自动化测试使用隔离数据和合成媒体。CPU 镜像已验证实际模型推理；NPU 镜像完成容器启动、运行库导入与模型文件检查，NPU 实机推理仍需在匹配硬件上核对。发布安装包不会自动部署到用户设备。
