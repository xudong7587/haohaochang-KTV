# v1.1.2 · B 站登录收回为一处

1.1.1 把在线找歌和收藏夹拆成了两份登录，需要在两个地方分别扫码。本版合并回一份：登录一次，在线找歌和收藏夹同步共用同一个账号。

- “设置与任务 → 在线资源”只有一张“B 站登录”卡片：在线搜索、预览、在线下载、更新画质、收藏夹同步和收藏夹下载都用它。
- bili-sync 五个字段的手动填写和“清除已保存凭证”也在这张卡片里（默认收起）；ac_time_value 不再是必填，应用内扫码会自动保存刷新令牌。
- 收藏夹卡片只保留启用、收藏夹 ID、检查间隔、保存和“立即同步已保存的收藏夹”。

## 这次如何更新

只更新 NAS 主镜像，不需要更换 Compose、分离镜像或 APK：

```sh
docker compose pull ktv
docker compose up -d --no-deps ktv
```

ARM64 在两条命令的 `compose` 后加上 `-f docker-compose.arm64.yaml`。CPU／NPU 容器保持原样，主镜像版本可用 `1.1.2` 或 `latest`。

在 1.1.1 里分开登录过的，两份凭证会自动并回一份：优先保留带刷新令牌、能自动维护的那一份，另一份删除，收藏夹 ID、检查间隔和启用状态都保留，通常不需要重新扫码。收藏夹要换成另一个账号时，只在这唯一的登录处重新扫码或填写凭证即可，两处会一起切换。

APK 与 1.1.0.1 功能相同，已经安装的电视、手机和平板不必更新；PC 整理器与分离镜像同样不受影响。

收藏夹下载若提示“请确认 B 站登录 Cookie 和当前账号清晰度权限”，先点“检测登录状态”确认账号与该账号的清晰度权限（4K 与 Hi-Res 需要大会员），再重试任务；重新收藏视频不会改变结果。
