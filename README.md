# 好好唱 · 家庭 KTV · v1.1.2

本版把 B 站登录收回到一处：在线找歌和收藏夹同步共用同一份 Cookie，只需扫码一次。APK 功能与 1.1.0.1 相同，已经安装的电视、手机无需更新。
把曲库放在家里的 NAS，打开电视、手机或平板，就能点歌开唱。好好唱把歌曲整理、伴奏制作和多端播放接在一起，日常使用不必反复搬文件。

[下载最新版本](https://github.com/xudong7587/haohaochang-KTV/releases/latest) · [使用手册](docs/USER-GUIDE.md) · [更新记录](CHANGELOG.md)

## 项目亮点

- NAS 集中管理曲库，自动识别歌曲资料，匹配歌曲／专辑图片、歌手照片和同步歌词。需要核对的内容留在任务列表中，也能批量整理或手动修改。
- 网页和 Android 都能接入歌房。同一个 APK 适配 TV、手机与平板；浏览器打开 `/play` 即可播放，扫码打开 `/mobile` 则只负责点歌和控制。配置好可访问的 HTTPS 地址后，也能远程接入。
- 自带人声分离，优先使用 PC 的 NVIDIA GPU 加快伴奏生成；支持具备相应驱动的 Intel NPU，NAS CPU 可接续处理。视频兼容转换还可使用 NVENC、Quick Sync 或 AMF，按硬件能力选择。
- 本地文件、授权链接和收藏内容都可导入，下载、资料匹配、裁剪、分离和入库衔接为任务流程。可以查看阶段、补齐信息、取消或重试，已有可用资源在处理失败时仍会保留。
- 较重的整理和分离工作放在 NAS／PC，TV 专注点歌、硬件解码与歌词显示。Android 原生播放保留同一个播放器，切换点歌页不重新加载画面；实际可播分辨率和编码取决于电视的解码能力。
- 支持拼音首字母点歌、原唱／伴奏切换、歌词校时和自动开场音乐。横竖屏调整导航与卡片布局，手机竖屏把视频居中放大；默认共用家庭歌房，也可开启互不打扰的独立歌房。

## v1.1.2 更新要点

- “设置与任务 → 在线资源”只保留一处“B 站登录”，扫码一次即可；在线搜索、预览、在线下载、更新画质和收藏夹同步、收藏夹下载都使用这份 Cookie。
- 1.1.1 里分开保存的两份登录会自动合并回一份，优先保留仍带刷新令牌、能自动维护的那一份，不需要重新扫码。
- 手动填写 bili-sync 字段的入口移到同一个登录卡片里（默认收起），ac_time_value 不再必须；应用内扫码会自动保存刷新令牌。
- 只更新 NAS 主镜像即可；CPU／NPU 分离镜像、PC 整理器和 APK 都不用重装。

## v1.1.0 更新要点

- 主程序、CPU 和 Intel NPU 分离容器拆开，Compose 自动配置内部地址与鉴权。主程序保留 Python、FFmpeg 和下载工具。
- CPU／NPU 固定在已经验证的 1.0.8 镜像及摘要；普通 Release 只构建主镜像，以后日常升级只重建 ktv。

## 我需要准备什么？

需要一台能运行 Docker 的 NAS、一台 Android 播放设备或电脑浏览器，以及连接到播放设备的麦克风和音响。好好唱负责播放音乐，没有手机录音、麦克风返听或唱歌评分。Windows PC 为可选加速设备。

NAS 主镜像支持 amd64 与 ARM64。PC GPU 分离需要支持 CUDA 的 NVIDIA 显卡；Intel NPU 需要对应设备及驱动，不适用于所有 NAS。条件不满足时可使用 CPU，处理速度会受硬件影响。详细条件见 [NAS 分离说明](docs/NPU.md)。

## 先把第一首歌唱起来

### 1. 在 NAS 安装

从 Release 下载 `haohaochang-nas-v1.1.2.zip`，解压后按架构导入 `docker-compose.yaml`（Intel／AMD x86）或 `docker-compose.arm64.yaml`（ARM64）。主程序与分离容器自动连接，电视和 PC 保留自动发现。

设置至少 12 位的管理密码，并映射三个目录：`/data` 保存数据库、任务、设置和模型缓存，`/media` 保存正式曲库，`/download` 暂存导入内容。默认端口为 `43210`，升级时沿用原端口和目录。

按 Compose 中的“必须修改／核对目录”注释填写。默认使用同目录下的 `data`、`media`、`download` 文件夹；如果更改 data 路径，CPU／NPU 的 `/data` 映射也要填写同一路径。三个容器均使用 host 网络，无需分配 Docker 子网，避免默认网络地址池耗尽导致部署失败。

镜像仍为 `ghcr.io/xudong7587/haohaochang:latest`，可公开拉取。启动后打开 `http://NAS-IP:端口/admin`，输入管理密码。从 v1.0.7／v1.0.8 升级需替换 Compose、拉取新版 ktv 并启动整套服务；保留原 data。以后日常只执行 `docker compose pull ktv` 和 `docker compose up -d --no-deps ktv`。完整步骤见 [NAS 安装与升级](docs/NAS安装与升级.md)。

### 2. 导入并整理歌曲

把已有文件放入曲库目录，在后台扫描；也可以在“在线找歌”中选择有权使用的内容、粘贴授权链接或导入收藏内容。确认片段后，系统继续处理图片、歌词和播放资源。仅处理自有或已获得相应许可的媒体。

需要电脑加速时，下载 `haohaochang-resource-ai-v1.1.2.zip`，在 Windows 解压并运行 `start.cmd`。首次会下载运行环境，启动后 NAS 可连接它处理任务。“人声分离”页面集中显示 PC、NPU 和 CPU 状态，处理顺序为 PC → NPU → CPU → 已配置的外部 API。

已有原唱和伴奏的半标准歌曲可以先唱，再补视频；缺少歌词不阻止点歌。资料不明确时，在编辑器中核对；失败任务可重试，旧资源继续保留。

### 3. 打开播放设备

Android 电视、手机和平板使用同一份 `haohaochang-tv-v1.1.2.apk`（与 1.1.0.1 功能相同）。首次启动寻找同一局域网中的 NAS；找不到时手动输入地址，再按提示扫码登录。电脑或浏览器直接打开 `/play`。如浏览器限制有声自动播放，点一次播放即可开始。

打开播放端会接续已点歌曲；没人点歌时播放随机原唱。同一轮先覆盖可用曲库，新入库歌曲更优先。默认歌房由 TV 优先播放，网页不会抢走正在使用的 TV。

只想遥控时，用手机扫描歌房二维码，进入 `/mobile` 点歌、暂停、切歌或发送掌声。需要分开唱时，网页点击“独立歌房”，APK 在设置中选择“独立歌房 / 输入号码加入”。独立歌房共享曲库，各自保存队列和播放状态。

## 日常使用

- 点歌页直接输入拼音首字母，左箭头退格，垃圾桶清空。放大镜和排序按钮在字母区下方；点击放大镜再输入完整歌名或歌手。
- 曲库支持行列表和海报墙、分页筛选、多选整理及歌名／歌手／时间排序。隐藏歌曲可恢复，需要清理时再使用“彻底删除”。
- “编辑歌曲”可修改资料、封面、视频和歌词。歌星管理可维护照片与介绍，点歌端使用相同资料。
- 歌词可以自动匹配，也能搜索多个候选、预览后保存。已有视频字幕时可隐藏系统歌词；歌词偏移按歌曲保存在 NAS。
- 更新画面会核对来源与裁剪范围；同一完整录音可保留原音轨，其他情况完整生成并校验后替换，失败时保留旧版。
- 视频默认保留原编码、分辨率和帧率。遇到设备不支持的编码，可使用 PC 兼容转换。
- 遥控器支持方向键移动卡片和自动滚动。手机触屏直接点击，横竖屏切换不重建播放器；竖屏视频填满播放区域，会裁掉部分两侧画面。

完整的导入、合集资料、取消任务、歌词微调和排错操作见[使用手册](docs/USER-GUIDE.md)。

## 怎么更新？

本轮需要同时更新 NAS 和 APK，才能获得完整的随机播放与手机界面改进。PC 协议保持兼容，可以继续使用已有整理器；新安装包的下载链接已指向改名后的仓库。

| 更新部分 | 操作 |
| --- | --- |
| NAS | 本次先更换 Compose、拉取新版 ktv 并启动整套服务；以后只更新 ktv，保留目录、密码和端口 |
| TV／手机／平板 | 下载本版 APK，同签名覆盖安装，保留登录 |
| PC 整理器 | 等任务完成后退出，解压新版 ZIP 覆盖，保留 `worker.json`、`runtime`、`.venv` 和 `data`，运行 `start.cmd` |

应用内更新入口仍隐藏，请从 Release 手动下载。仓库改名不改变镜像地址、安装包名称或 NAS 目录映射。
